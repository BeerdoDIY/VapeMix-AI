# VapeMix AI 💨
An AI-powered progressive web app (PWA) for managing DIY e-liquid recipes and inventory.

## Features
* **Recipe Management:** Manage your recipes and track and rate your mixes with full import and export capability.
* **Mix Calculator:** Easily update your ratios and strength and mix by weight or volume with accurately calculated cost tracking.
* **Inventory Tracking:** Manage your concentrates and bases and create a shopping list for flavours you need.
* **Smart Invoice Import:** Import your invoices by text or pdf and instantly update your stash and cost per ml.
* **AI Recipe Assistance:** Leveraging Gemini to help refine flavor profiles.
* **PWA Ready:** Installable on Android, iOS, and Desktop.
* **Firebase Sync:** Keep your recipes synced across devices.

## Getting Started

### Prerequisites
* Node.js installed

### Installation
1. Clone the repo: `git clone https://github.com/BeerdoDIY/VapeMix-AI.git`
2. Install dependencies: `npm install`
3. Create a `.env` file based on `.env.example` and add your Gemini API Key.

### Development
Run the app locally:
`npm run dev`
